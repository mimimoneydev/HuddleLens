# Three-minute demo script

**0:00–0:18 — Hook**  
“Four people can watch the same goal and have four different experiences. HuddleLens makes sure nobody is left outside the huddle.” Show the home screen and use only the Fire TV remote.

**0:18–0:42 — TV-native live experience**  
Select **Watch live**. Point out the unobtrusive AI Lens prompt during the simulated match. Mention that it appears only at high-impact moments.

**0:42–1:20 — The magic moment**  
Select **Show me**. Explain the plain-language insight and play the animated movement. Change detail from Rookie to Fan to prove personalization.

**1:20–2:00 — Family movement**  
Open **Start a family Move Break**, start the challenge, then alternate Left and Right on the remote until completion. Emphasize the no-camera fallback and privacy-first camera roadmap.

**2:00–2:32 — Accessibility**  
Open the accessibility mixer and toggle calm commentary and high-contrast play. Explain that the settings live one click from the match and save per viewer.

**2:32–2:52 — Architecture**  
Show a brief slide or repository diagram: Fire TV event adapter, explanation provider, and on-device motion provider. State clearly that the reliable MVP uses deterministic match data and is ready for Bedrock/live-feed adapters.

**2:52–3:00 — Close**  
“HuddleLens turns spectators into a team—understanding, moving, and cheering together.” End on the completed family challenge, not a code editor.
